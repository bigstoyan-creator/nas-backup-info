# Privacy policy — NAS RustDesk Backup

Last updated: 1 November 2026

## Purpose and operator
Stoyan Toshev operates this application for personal backup
and disaster recovery. It is not offered to other users.

## Data and permissions
The application creates encrypted archives containing local
RustDesk server data, keys and container configuration.

Google Drive access uses the drive.file permission to upload
and manage files created by this application. File metadata
is used to locate and verify backups. The application does
not request access to unrelated Drive files, Gmail messages
or contacts.

## Security and sharing
Archives are encrypted before upload and remain private.
OAuth tokens and credentials are stored on the owner's NAS
with restricted filesystem permissions.

Google Drive stores the encrypted archives. The configured
email provider delivers status notifications to the owner.
Archive passwords are not included in these emails.

Data is not sold, used for advertising or used to train AI models.

## Retention and control
The owner can delete archives from the NAS and Google Drive.
Configured retention rules may also remove older backups.
Deleted Drive files may remain in trash until it is emptied.

The owner can revoke access in Google Account settings.
Revoking access does not automatically delete existing backups.

## Website
This static site has no analytics scripts or advertising.
GitHub Pages may process technical request information under
GitHub's privacy statement.
